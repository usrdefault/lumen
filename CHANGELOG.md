# v0.1.1 - 24.11.2026 (d.m.y)
## Fixed
- Shortcuts: Settings > Shortcuts now says clearly when a shortcut could not be registered and why (already used by another application, same as another Lumen shortcut…). Alt+Shift and Ctrl+Shift also switch the keyboard layout in Windows when you have several: Lumen warns you when you pick one of them, since it may not trigger (or may change your language at the same time).
- Timer notch: it is bigger and stuck to the top edge of the screen instead of floating, slides in and out of the edge, widens smoothly when a timer ends (no more shaking), and has a right-click menu.
- Settings and welcome windows now have the same rounded corners as the launcher on Windows 10, and the corner radii of cards, fields, buttons and chips are the same in the launcher, settings, welcome and editor.
- Sharing: "Token refused (401)" is easier to fix. Lumen now cleans the pasted token (spaces, line breaks), tells you to paste the "Token" line and not the "Hash" line, accepts a token of another shape with a warning, and if your host strips the usual header, Lumen notices it and uses a second one for that server. After a refusal, "Test connection" tells you what is wrong (header removed by the host, or token not matching) and a short help explains the usual causes. The server has a new `GET /api/ping`, a better `php tools/check.php` (which configuration file is loaded, is the hash set) and `php tools/check.php --verify` to check a token. Update the server with the new zip.
- Middle-click paste of the selection: rewritten. A selection is now kept when you let go after dragging over text (at least 6 px and a short moment), or after a double or triple click, and it no longer changes afterwards; Lumen retries reading it for a moment if the app is slow, and also reads classic Windows text boxes. Pasting is always instant (no more letters typed one by one) and the click puts the cursor where you clicked first. Your clipboard is put back as before, now including images, files, rich text and HTML; if something in it cannot be saved (like an old-style bitmap), the paste still happens and the rest is restored. If pasting would lose your clipboard (for example a very large image that cannot be saved), nothing is pasted and you are told. A partial restore, or a clipboard wiped because it held a secret, is announced by a discreet notification and noted in Settings. Reading a selection in browsers wakes their accessibility tree with a short limit, so Lumen never waits long on a slow app.
- Publishing: the release script finds a build made with a different output folder (`CARGO_TARGET_DIR`).

# v0.1.0 - 24.11.2026 (d.m.y)
## New
- First installable version of Lumen: a Spotlight-style launcher for Windows, opened with Alt+Space.
- Launch applications (Start menu and Store apps), open known websites and addresses, run web searches, find files.
- Calculator and offline unit conversions.
- Clipboard history (text and images, encrypted on disk, password managers ignored) and an emoji picker.
- Screenshots with an annotation editor, and screen recordings (MP4 or GIF).
- Linux-style primary selection: select text, then middle-click to paste it.
- Settings window, welcome tour, light and dark themes with accent colours, remembered window position.
- Installer for the current user (no administrator rights), in French, with a Start menu shortcut.
- Automatic updates: Lumen looks for a new version in the background (never takes the focus, never during a screen recording), shows a line in the launcher with the release notes, and installs on request or automatically if you enable it in Settings.
- Extensions: add your own results to Lumen without touching its code, "like browser extensions but for the launcher". An extension is a folder with a `manifest.json` (and an optional `icon.png`): **declarative only, no code is ever run** (no JavaScript, scripts, programs or DLLs). It picks from a closed list of commands (`open_url` with the typed text in a website address, `list` of fixed lines, `fetch_json` which reads a public web service, with up to two chained requests and simple extraction paths). It only reacts to its own keywords (`weather Paris`), never to other typing. Settings > Extensions (or type `extensions`): list with icon, version, author, domains, on/off switch and delete; install from a folder or a .zip through the native file dialogs. Before installing, a screen shows the name, author, description, keywords and **the domains contacted** and says clearly that what you type after the keyword is sent to them; nothing is written until you accept, and any change of domains (update or edit on disk) asks again. Strict validation with clear errors (field and reason); a bad extension is refused entirely; keywords cannot clash with Lumen's own or another extension's. Network: https only, declared domains only, GET, no custom headers, cookies or keys, 5 s and 1 MB limits, redirects only to declared domains, local and private addresses refused, requests sent 350 ms after the last keystroke, 20 per minute per extension. Unsafe zips (path traversal, extra files, too big) are refused. Texts from extensions are cleaned and shown as plain text; actions are limited to opening an address of a declared domain or copying text. Four examples in `extensions-examples/` (weather, GitHub search, translate, Wikipedia) and a guide in `docs/extensions.md`.
- Scrolling capture (whole page): choose a zone or a window and Lumen scrolls it with the mouse wheel, takes an image at each step and stitches them into one tall picture (thumbnail, editor, copy, save, share and text copy work as for any capture). Start it with Ctrl+Alt+Shift+Print Screen (Ctrl+Shift+7 on keyboards without Print Screen), the `D` key or the "Scrolling" button in the capture selection, `scrolling capture` / `long capture` in the launcher, or the tray menu. Fixed headers and footers are kept once, it stops by itself at the end of the page (or at 20,000 px), Esc or "Finish" keeps the result, "Cancel" drops it. A small floating bar (left out of the capture) shows the height so far; its Auto / Manual button lets you scroll yourself while Lumen captures when the content changes (default in Settings > Capture). Lumen only scrolls the window that was under the zone when you chose it, never clicks, never scrolls while Ctrl, Shift, Alt or Windows is held, never during a game or a full-screen app, and stops if you move the mouse.
- Timers and reminders, Dynamic Island style: type `5 min pasta`, `timer 10m`, `25 min`, `1h30 meeting`, `remind me at 6pm call mom`, `rappel demain 9h dentiste` or `chrono` (French and English, "in 10 minutes", "at 6pm", "tomorrow"); the result shows the end time and Enter starts it. A black notch stuck to the top edge of the screen, like the one on a Mac, slides down from the edge and shows the time left. Hover it for big digits, a progress bar and the buttons (pause, +1 min, stop). When a timer ends it widens from the edge with a soft glow and two buttons, OK and +5 min. Right-click it for a menu: pause or resume, +1 min, +5 min, restart, stop, stop all, open the list of timers, hide the notch (the timers keep running). It never takes the focus, lets clicks through around it and stays hidden during games and full-screen apps (a Windows notification is sent instead, and it appears when you come back). Type `timers` to list them (Enter pauses or resumes, Ctrl+Delete cancels). Timers survive a restart of Lumen and what rang while it was closed is shown at the next launch. Settings > Timers: pill on or off (notification only), screen, chime on or off and volume. The chime is generated by Lumen itself.
- Windows settings from the launcher: type `bluetooth`, `sound`, `wifi`, `display`, `updates`, `mouse`, `keyboard`, `printers`, `storage`, `battery`, `notifications`, `wallpaper`, `apps`, `startup`, `privacy`, `microphone`, `camera`, `vpn`, `proxy`, `time`, `language`, `accessibility`, `firewall`, `backup`, `task manager`, `control panel`, `device manager`... (French or English, accents optional) to open the matching page. A closed list: the interface cannot make Lumen open anything else. Lumen's own commands (theme, update, settings) still come first.
- System commands: `lock`, `sleep`, `hibernate` (when enabled), `log off`, `restart`, `shut down` (no administrator rights needed), `empty recycle bin` (shows the item count and size), `mute`, `volume +` and `volume -`. Shutting down, restarting, logging off, hibernating, emptying the recycle bin and forcing an app to quit need a second Enter within 3 seconds, enforced by the core and not only by the interface.
- `stop <app>` (also `close`, `quit`, `kill`): lists your apps that have a visible window; Enter asks the app to close properly, Ctrl+Enter forces it (with confirmation). Lumen itself, system or protected processes and other users' processes are never offered; an app running as administrator is refused cleanly; Windows Explorer needs a special confirmation. In the sandbox none of these actions runs.
- Text shortcuts: Settings > Texts lets you define abbreviations (`;mail`, `;adr`, multi-line allowed) with the variables `{date}`, `{time}`, `{clipboard}` and `{cursor}`. Type one in the launcher: Enter pastes it into the previous window (it never enters the clipboard history and your clipboard is restored), Ctrl+Enter only copies it. Encrypted with Windows on disk, JSON import and export through the native file dialogs (the export is not encrypted). Lumen does not watch the keyboard: there is no expansion while typing in other apps.
- Screen colour picker: Ctrl+Alt+Print Screen (Ctrl+Shift+6 on keyboards without Print Screen), or type `color` / `eyedropper`, or the tray menu. The frozen screen and a large magnifier show the colour code live; click or Enter copies it, arrow keys move one pixel (Shift: ten), Tab changes the format (HEX, rgb(), hsl(), plain values; also in Settings > Capture), Esc cancels. A thumbnail confirms "#1E90FF copied". Type `colors` for the last 20 colours (Enter copies again, Ctrl+Enter in the next format).
- Share by link: a "Share" button in the screenshot thumbnail (screenshots, MP4 and GIF recordings) and in the editor (Ctrl+Shift+U) sends the file to your Lumen Share server, copies the link and shows "Link copied", with progress in the button. Settings > Sharing: server address (https only), token (stored encrypted with Windows, never shown again), connection test and default expiry. Type `shares` (or `gallery`) in the launcher to list your links, copy one (Enter), open it (Ctrl+Enter) or delete it (Ctrl+Delete, then Enter). Nothing is sent without a click on Share. The token is tied to the server address: changing the address asks for confirmation and deletes the token.
- Copy the text of a screenshot, offline: draw a zone (Ctrl+Shift+Print Screen, or type `text` / `ocr` in the launcher, or the tray menu) and the recognised text is copied to the clipboard; a thumbnail shows its first lines. A "Copy text" button is also in the thumbnail and in the editor. Uses the text recognition built into Windows (no connection, nothing written to disk); small zones are enlarged before reading, columns and paragraphs are rebuilt.

## Fixed
- Screen selection: the MP4 / GIF chooser was shown in every mode instead of the recording mode only.
- Text capture: the recognised text and the pixel buffers are now really zeroed (not just freed), and the text is wiped as soon as the capture is forgotten.
- A screen recording and an update installation can no longer start at the same instant (one atomic lock for both).
- Release script: the changelogs are pushed to the public repository only after the release is published, and an already published release is not republished without `--force`.
- Sharing server: files are served with `Cache-Control: private, max-age=3600` at most.
- Updates: a check can no longer overwrite an installation in progress, a failed installation is the only case that offers the update again, and a screen recording cannot start while an update is installing.
- Release scripts: the release is published only once the installer, its signature and latest.json are all uploaded; the signed version is checked; the public key is checked like the app does; long changelogs no longer hit the Windows command-line limit; the version bump checks every file before writing any.
